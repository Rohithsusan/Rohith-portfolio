MOBILE APP DESIGN

IceBrekr

Connection App — Smart Contact Management & Networking

By Rohith Susan — UI/UX Designer

🎨 View Design in Figma →

In today's hyper-connected world, we meet people constantly — at networking events, webinars, and online forums. Yet our contact lists quickly become cluttered. We forget why we saved someone, what we discussed, or when we should reconnect.

IceBrekr is a mobile app I designed to explore how contact management could feel more personal, contextual, and follow-up friendly — built for real relationships rather than just digital records.

The UX Problem

💡 "Users save names but lose context — and with it, the opportunity for meaningful follow-ups."

Our smartphones make it easy to save contacts, but current tools don't help us remember the why — the event, the moment, or the promise to reconnect.

The problem was clear: users need a smarter system that helps them remember connections, set reminders, and separate work from life — without overwhelming them.

Competitive Analysis

I evaluated tools like Popl, Covve, and Blinq for UX opportunities:

Covve

Strengths: Enriched contact intelligence
UX Gaps: Poor support for dual profiles and personalized follow-up reminders

Blinq

Strengths: Sleek digital business card UI
UX Gaps: Limited use beyond professional context

Popl

Strengths: Seamless NFC-based contact sharing
UX Gaps: No support for contextual memory or long-term relationship tracking

IceBrekr differentiators: Context-first design • Reminder-based flow • Dual personas for personal/professional separation • Flexible tagging & export features

Design System & Component Strategy

I created a responsive, mobile-first design system in Figma with Auto Layout components, variants for icons/inputs/buttons, reusable frames for profile cards and reminders, color & type tokens for clarity and hierarchy — designed with handoff-readiness for development in mind.

By skipping wireframes, I saved time and invested in a scalable component-based design that sped up iterations and prototyping.

Design Evolution

Clean, modern interface with reduced cognitive load

Key Improvements Made

  • Reduced Cognitive Load: Removed overlapping floating elements, grouped related interactions, updated spacing and typography
  • Lower Interaction Cost: Simplified journey for top user intentions — discover people, switch events, search & filter
  • Minimalistic + Functional: Soft backgrounds, simplified icon set, uniform card height, consistent 4-point spacing grid
  • Visual Hierarchy: Profile image → primary identification, Name → highest font weight, Action icons → secondary importance
  • Scalable Design System: Reusable components for event selection, search + filter bar, profile cards, notification badges

Polls, Saved Content & Micro-Interactions

As part of extending IceBrekr's communication features, I designed a lightweight interaction module supporting poll creation, saved drafts, and scheduled posts — ensuring users could not only manage contacts, but also actively engage with them in a contextual and timely manner.

UX Problem

Users plan interactions like polls in advance, but without a save or schedule system, content gets lost or rushed.

Design Solutions

Saved poll timestamps • Save/unsave with toast notifications • Scheduled poll editing • Quick actions (pin, copy, delete)

Testing & Feedback

Tested the prototype with 3 early users and gathered qualitative feedback via Notion:

  • What Worked: Tagging + notes appreciated, reminder timeline intuitive, QR scanner smooth
  • What Needed Fixing: Tag-based filtering missing, profile switching confusion, typography too small

Improvements made: Added onboarding tooltip for profile switching, introduced tag filter in contact list, adjusted mobile typography for readability.
